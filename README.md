# Labs-Electronic

Бесплатный локальный стенд для лабораторной работы по цифровой электронике.
Симулятор — [CircuitJS1](https://github.com/pfalstad/circuitjs1), схема хранится
в репозитории как обычный текстовый файл и открывается без аккаунта и оплаты.

## Запуск

Требуется только Docker Desktop.

```bash
docker compose up -d --build
```

После сборки открыть: <http://127.0.0.1:8082>

Первая сборка загружает исходники CircuitJS1 и может занять несколько минут;
повторные запуски используют кэш Docker.

Остановка:

```bash
docker compose down
```

## Что находится в стенде

Основная схема `keyboard-matrix-5.txt` повторяет последовательность блоков из
конспекта преподавателя:

1. прямоугольный генератор 0…5 В, 10 Гц;
2. двухразрядный асинхронный счётчик на двух D-триггерах;
3. дешифратор 2→4 на NAND с активными низкими выходами `C0#…C3#`;
4. кнопочная матрица 2×4 с подтяжками 10 кОм и развязывающими диодами;
5. установленные кнопки `K1…K4` в первой строке и `K5` в позиции `R1×C0`;
6. определение нажатой кнопки и логика семисегментного индикатора для цифр 1…5.

Кнопки изначально разомкнуты. Щёлкните `K1`…`K5`, чтобы замкнуть нужную
кнопку. Для изменения элемента используйте правый клик; на Mac также работает
`Control` + клик.

Автоматическая проверка находится по адресу <http://127.0.0.1:8082/test.html>.
Она прогоняет все пять кнопок, четыре состояния счётчика, сегменты индикатора и
RC-генератор.

## Как сохранить свою работу

После изменений выберите **Файл → Сохранить как…** — браузер скачает
редактируемый `.txt`-файл CircuitJS. Его можно снова открыть кнопкой выбора
файла в правой панели симулятора. Чтобы сделать вариант постоянной частью
стенда, замените им файл в `circuits/` и повторите `docker compose up -d --build`.

## Почему не EveryCircuit

EveryCircuit блокирует запуск этой схемы ограничением размера и предлагает
платную разблокировку. CircuitJS1 свободен по GPL, поддерживает реальные
резисторы, конденсаторы, диоды и переключатели, а также цифровые D-триггеры,
логические элементы и семисегментный индикатор. Поэтому схема не заменена
картинкой или упрощённой демонстрацией — она остаётся редактируемой моделью.

## Файлы

- `circuits/keyboard-matrix-5.txt` — полная схема для запуска.
- `circuits/clock-rc-notebook.txt` — отдельный RC-генератор из конспекта для
  исследования; в полной схеме используется идеальный Pulse 10 Гц, чтобы
  запуск счётчика был устойчивым.
- `docs/notebook/` — исходные фотографии конспекта.
- `docs/SCHEME_MAP.md` — точное соответствие блоков конспекта и модели.

CircuitJS1 при сборке фиксируется на конкретном коммите upstream, указанном в
`Dockerfile`, поэтому стенд не меняется самопроизвольно.
